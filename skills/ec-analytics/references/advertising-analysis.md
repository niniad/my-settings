# 広告分析フレームワーク詳細

## 分析軸と操作軸

**分析軸（広告効果の実態を見る単位）**

| 軸 | 内容 | データソース |
|---|---|---|
| 広告掲載商品 | どのASINを広告したか | `stg_ads_product_daily` |
| 実購入商品 | 何が実際に売れたか（クロス購入含む） | `stg_ads_cross_purchase` |
| ターゲット | KW・ASIN、何に反応したか | `stg_ads_keyword_daily` |
| 検索語句 | 実際に入力されたワード | `stg_ads_search_term_daily` |
| 掲載枠 | どこに表示されたか | `amazon_ads_v1_external.sp_product_search_term_placements` |

**操作軸（変更できる単位）**

| 操作単位 | 変更できるもの |
|---|---|
| キャンペーン | 予算・入札戦略・掲載枠調整% |
| 広告グループ | デフォルトbid |
| KW/ターゲット | 個別bid・有効/停止 |

> **キャンペーンは「予算とbid戦略を共有するグルーピング」に過ぎず、分析の主軸ではない。**

## 広告最適化の判断順序（必ず守る）

**Step 0: 同一キャンペーン/ターゲットの検証中テストを確認する**
- PDCA_Actions から Status=検証中 のアクションを全件取得
- 分析対象のキャンペーン名・KW名が、検証中アクションの Title または Outcome に含まれるか照合
- **該当あり かつ DueDate > 今日 → 変更提案を禁止**。代わりに以下を表示:
  「検証中（Action #XX「タイトル」、期限YYYY-MM-DD）。中間経過: [現在の数値]。DueDate到来後に判断する。」
- 該当あり かつ DueDate ≤ 今日 → 検証結果を評価してActionを完了/延長する
- 該当なし → Step 1 へ進む

**Step 1: 分析軸で問題の所在を特定する**
- 「どの検索語句が」「どのターゲットに対して」「どの掲載枠で」「何を購入させているか」を確認
- キャンペーン単位の数字は出発点に過ぎない

**Step 2: 変更対象の粒度でクリック数が十分か確認**
- 掲載枠別調整: 掲載枠ごとに20クリック以上（CVR 5%なら期待値1件）
- KW/ターゲット別: 20クリック以上（不足なら費用閾値で停止判断）
- → **不足なら「データ不足。観測を続けるか費用閾値で停止する」と明示してアクション提案しない**

**Step 3: 操作軸に変換して変更を提案する**
- 分析結果を「キャンペーン/KW/ターゲット単位の変更指示」に落とし込む
- 掲載枠調整はキャンペーン全体に一律適用される点に注意（特定KWだけTop調整はできない）

**Step 4: NG判断パターン（これをやったら間違い）**
- 「粗利率が高いから広告予算を集中させるべき」→ **ロジックエラー**。粗利率 ≠ 広告ROAS
- 「このキャンペーンのACOSが悪い」→ **キャンペーン単位で判断しない**。KW×掲載枠で確認
- 「掲載枠別データで転換ゼロ」→ **クリック数20未満なら判断保留**。ゼロか低確率かの区別ができない
- 「KWを停止してもデータは後で集まる」→ **停止したら永久にデータが集まらない**。停止は慎重に

## キーワード停止の正しい基準

**停止してよい条件（AND条件）**:
- combined ACOS（Top＋Detail合計）が損益分岐ACOS（56%）を **大幅に** 超えている
- かつ 費用が一定額（例：¥2,000/月）以上かかっている
- かつ 3ヶ月以上継続している

**停止してはいけない場合**:
- combined ACOS が損益分岐以内（例：32-60%）なら停止不要
- クリック数が20未満（ノイズで悪く見えているだけかもしれない）
- Top転換ゼロでもDetail転換がある（「食事エプロン」のケース：Detail ACOS 24.8%は優秀）

**停止の代替手段**:
- bidを下げる → 高すぎる掲載枠（Top）の露出を減らしつつデータは蓄積できる

## 掲載枠調整の意味

| 設定値 | 意味 | Top CPC（ベースbid¥25の場合） |
|---|---|---|
| 0% | ベースbidと同じ（1倍） | ¥25 |
| 50% | 1.5倍 | ¥37.5 |
| 100% | 2倍 | ¥50 |
| 150% | 2.5倍 | ¥62.5 |
| 450% | 5.5倍 | ¥137.5 |

> Fixed bid キャンペーン: ベースbid ≈ Detail CPC（Detail調整は通常0%）
> Top CPC = ベースbid × (1 + Top調整%)

## クロス購入の必須確認

広告停止・変更時は必ず `rpt_ad_cross_purchase` でクロス購入を確認。
全商品でクロス購入率64〜79%。`true_roas` = クロス購入込み総売上 / 広告費 で評価する。
