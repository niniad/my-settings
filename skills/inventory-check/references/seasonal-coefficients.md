# 季節係数・セール補正

## 季節係数（エプロン・3枚セット共通）

2025年実績（parent: B0D898XK3W）から算出。毎年1月初旬に更新すること。

| 月 | 係数 | 特徴 |
|----|------|------|
| 1月 | 0.98 | 閑散期 |
| 2月 | 1.02 | 閑散期（ベース） |
| 3月 | 1.59 | 繁忙期（入園準備） |
| 4月 | 1.52 | 繁忙期（入園・進級） |
| 5月 | 0.93 | 普通 |
| 6月 | 0.89 | 普通 |
| 7月 | 1.02 | 普通 |
| 8月 | 1.26 | やや高（お盆前購買） |
| 9月 | 1.47 | 繁忙期（秋の入園） |
| 10月 | 1.54 | 繁忙期 |
| 11月 | 1.42 | やや高 |
| 12月 | 0.54 | 低 |

**適用方法**: `days_until_stockout` を月ごとの実消費量でシミュレーションして再計算する（翌月以降の係数を将来在庫に適用）。

リュックは2026年1月ローンチのため季節データなし → フラット計算。

## セール・イベント補正

**テーブル追加不要。チェック時に口頭で補正を指定する。**

起動例:
```
在庫チェックして。4/1〜4/7にセール予定で1.5倍想定。
```
```
在庫チェック。Prime Day (7/11〜12, 2日間) は3倍想定。
```

スキルはセール期間のみ `avg_daily_units × 倍率` でシミュレーションに組み込む。補正なしの場合は季節係数のみで計算。

主なセールイベント（参考）:
- 新生活セール: 3月下旬〜4月上旬
- Prime Day: 7月中旬（2日間）
- タイムセール祭: 不定期（通知で把握）
- Black Friday: 11月下旬
- サイバーマンデー: 12月上旬
