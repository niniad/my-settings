## テーブル構造

| カラム | 型 | 説明 |
|--------|-----|------|
| カテゴリー名 | Text | セラースプライトのサブカテゴリー名 |
| 月市場売上_円 | Currency | 最新3ヶ月平均 |
| 平均価格_円 | Currency | 市場平均価格 |
| SS粗利率_参考 | Percent | SS算出値（FBA手数料等のみ控除。仕入原価含まず。参考のみ） |
| A+割合 | Percent | 競合のA+コンテンツ採用率 |
| 平均評価数 | Number | 競合平均レビュー数 |
| TOP100月平均販売数 | Number | カテゴリーTOP100の月平均販売数 |
| ブランド集中度 | Decimal | 0〜1（1.0は寡占状態。0.7以下が参入しやすい目安） |
| L1通過 | Checkbox | Layer 1通過 |
| L1除外理由 | Text | 除外する理由（Layer 1） |
| L2通過 | Checkbox | Layer 2通過 |
| L2除外理由 | Text | 除外する理由（Layer 2） |
| ステータス | Select | 検討中 / 候補 / 除外 |
| 想定販売単価_円 | Currency | ユーザー入力 |
| 想定仕入原価_円 | Currency | ユーザー入力（1688仕入+国際送料+検品+関税+消費税込みの円換算コスト） |
| FBA手数料_円 | Currency | ユーザー入力（Amazonの料金シミュレーターで確認） |
| Amazon手数料率_% | Percent | デフォルト8%（カテゴリーによって異なる） |
| 月販数_安定後 | Number | ユーザー入力（安定後に見込める月販売数） |
| 広告割合_% | Percent | ユーザー入力（売上に対する広告費の割合） |
| 純粗利_個_円 | Currency | AI計算 |
| 月利益_安定後_円 | Currency | AI計算 |
| 12M累計利益_円 | Currency | AI計算（比較のメイン指標） |
| 年間利益率_% | Percent | AI計算 |
| 備考 | Text | 参入懸念・メモ |
