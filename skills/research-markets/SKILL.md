# Market Research（カテゴリー選定）

新商品カテゴリーをデータと事業方針の両軸で選ぶ。
判断基準: **12ヶ月累計利益が最大のカテゴリーを優先。ただし Layer 1/2 フィルターが先。**

---

## ワークフロー

```
Phase 1: Layer 1/2 フィルタリング
  → 「やりたくないこと」「できないこと」でNocoDB上の72カテゴリーを除外
  → ユーザーがステータスを「除外」「候補」に分類

Phase 2: 候補カテゴリーの利益シミュレーション入力
  → ユーザーが「候補」カテゴリーの想定コストを入力
  → AI が 12M累計利益を自動計算してNocoDB更新

Phase 3: 利益比較・優先順位付け
  → 候補カテゴリーを12M累計利益順でランキング表示
  → ユーザーがカテゴリーを決定

Phase 4: 選定カテゴリーの詳細リサーチへ
  → research-amazon-competitor スキルへ引き渡し
```

**スキル起動時は必ず NocoDB カテゴリー候補テーブルの現状をまず確認し、
どの Phase にいるかをユーザーに提示してから作業に入る。**

フィルタリング基準・計算式の詳細: [references/filtering-criteria.md](references/filtering-criteria.md)
NocoDB テーブル定義・接続情報: [references/nocodb-tables.md](references/nocodb-tables.md)

## Phase 1: Layer フィルタリング

**AIフィルタリング提案の手順:**
1. NocoDB から全カテゴリーを取得（ステータス問わず全件）
2. `filtering-criteria.md` の判定ルールに従い L1/L2 通過/除外を判定
3. 結果を [A]候補 / [B]除外提案 / [C]要確認 の3グループで提示
4. ユーザーが [C] に回答
5. 判定確定後 NocoDB を一括更新（`tmp/apply_filters.py`）

---

## Phase 2: 利益シミュレーション

### ユーザーが入力する項目

ステータス=「候補」のカテゴリーごとに以下を調べて入力:

| 項目 | 調べ方 |
|------|--------|
| 想定販売単価_円 | 競合価格帯を参考に Ufa の参入価格を決める |
| 想定仕入原価_円 | 1688.com で同等商品を検索、概算単価を (元×為替) + 送料・関税・検品を加算 |
| FBA手数料_円 | Amazonの料金シミュレーターで商品サイズ・重量から確認 |
| Amazon手数料率_% | カテゴリーごとに異なる。通常8〜10%。デフォルト8% |
| 月販数_安定後 | ブランド集中度・TOP100月平均販売数からUfaが取れる現実的なランクを推定 |
| 広告割合_% | 立ち上げ初期は30〜40%、安定後は15〜25%を目安 |

計算式・ランク推定ガイド: [references/filtering-criteria.md](references/filtering-criteria.md)

### 計算の実行方法

Python スクリプト（`tmp/` に保存して実行）で一括計算して NocoDB を更新する。

---

## Phase 3: 比較と優先順位付け

```
カテゴリー名 | 月市場売上 | 平均価格 | 純粗利/個 | 月利益 | 12M累計利益 | 年間利益率
```

ブランド集中度・平均評価数（参入難易度）も添えて総合的に判断。

### 決定基準

1. **12M累計利益が最大のカテゴリーを第1候補**
2. **ただし以下の条件で補正**:
   - ブランド集中度 > 0.95 → 実現可能性を割り引く
   - 平均評価数 > 500 → レビュー獲得に時間がかかる
   - 月市場売上が食事用スタイ（約30万円）の3倍以上 → 市場規模のポジティブ評価

---

## Phase 4: 次工程への引き渡し

カテゴリーが決定したら:

1. 選定カテゴリー名・決定理由を `decisions.md` に記録
2. NocoDB リサーチベースのカテゴリーを「候補」→ステータス変更（選定済みのマーク）
3. `/research-amazon-competitor` を起動

---

## AI支援の依頼パターン

| 依頼 | AIの動作 |
|------|---------|
| 「フィルタリングして」「Layer 1/2でチェックして」 | NocoDB一覧取得 → 除外候補提案 → ユーザー確認後更新 |
| 「候補を見せて」「残ったカテゴリーは？」 | ステータス=候補の一覧を市場売上順で表示 |
| 「利益計算して」 | 入力済みカテゴリーの利益を一括計算 → NocoDB更新 |
| 「ランキングを出して」「比較して」 | 12M累計利益順でカテゴリー比較表を表示 |
| 「カテゴリーを決める」 | 上位候補の最終比較 + decisions.md への記録 |
| 「セラスプデータを更新して」 | 最新の xlsx を読み込んで NocoDB データを上書き |
