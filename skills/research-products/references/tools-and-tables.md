# セラースプライト活用ガイド・NocoDB テーブル定義

## セラースプライト活用ガイド

### 推奨レポート取得順序（3ラウンド制）

```
Round 1: 市場バリデーション（この市場に参入すべきか？）
  ①市場リサーチ → ②商品リサーチ

Round 2: 競合ディープダイブ（誰と戦うのか？）
  ③ライバル商品リサーチ → ④レビューCSV → ⑤商品画像テキスト

Round 3: キーワード戦略（顧客はどう検索するか？）
  ⑥キーワード逆引き → ⑦キーワードマイニング
```

### 各レポートの詳細

| # | 機能 | 取得方法 | NocoDB格納先 | AI処理 |
|---|------|---------|-------------|--------|
| ① | 市場リサーチ | Web版で商品カテゴリ指定 | （分析のみ） | 市場規模/成長率/独占度を判定 |
| ② | 商品リサーチ | 条件指定で上位商品抽出 | Amazon競合商品 | ASIN,販売数,価格,BSR,評価等を登録 |
| ③ | ライバル商品リサーチ | 上位ASIN個別入力 | Amazon販売推移 | 月別販売数・売上推移を登録 |
| ④ | レビューCSV | Chrome拡張でダウンロード | Amazonレビュー | テキスト分析→スペックマスタ反映 |
| ⑤ | 商品画像テキスト | Chrome拡張で画像DL→AI OCR | Amazon商品画像テキスト | 訴求ポイント抽出 |
| ⑥ | キーワード逆引き | 競合ASINを入力 | キーワードデータ | 検索Vol/CPC/順位の分析 |
| ⑦ | キーワードマイニング | メインKW入力 | キーワードデータ | リスティング用KWリスト生成 |

### セラスプデータの精度

- **販売数は推定値**。実際の30〜50%程度と見積もる
- 相対比較（商品A vs B）には有効、絶対値としては過大
- 利益シミュレーションでは保守的に40%係数を適用

## NocoDB テーブル（商品カテゴリ別BASE）

商品カテゴリごとに NocoDB の BASE が分かれる。

| テーブル | 主な用途 |
|---------|---------|
| 企画プロセス管理 | フェーズの進捗管理（最初に確認） |
| スペックマスタ | スペック定義・優先度・判断基準 |
| Amazon競合商品 | 競合商品データ |
| Amazonレビュー | レビューテキスト |
| Amazon商品画像テキスト | 商品画像OCRテキスト |
| Amazon販売推移 | 月別販売数・売上 |
| キーワードデータ | 検索KW・Vol・CPC |
| 商品スペック | 商品ごとのスペック値（KV形式） |
| 利益シミュレーション | 原価/売価/利益の自動計算 |
| 1688商品 | 1688候補商品データ |
| 1688工場 | 1688候補工場データ |
| 工場チャットログ | 工場との問い合わせ記録 |

テーブル名は全ベースで統一。Table ID は Base ID からテーブル一覧を取得して名前で特定する。
