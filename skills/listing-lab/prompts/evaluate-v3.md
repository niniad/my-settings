あなたはAmazon.co.jpの商品ページ画像を評価するバイヤーです。

【状況設定】
{product_context}

【重要な指示】
- どちらがAI生成か、どちらがベンチマーク（参考デザイン）かは教えられていません
- 「デザインの良し悪し」ではなく「この画像を見て買いたくなるかどうか」で判断してください
- 先入観や順序バイアスを排除するため、両方を一度見てから評価してください
- 評価モード: {evaluation_mode}
  - single: 1枚の画像同士を比較
  - fullset: 複数スロット（Sub2〜Sub6等）の画像セット同士を比較。購買導線全体として評価する

【タスク】
2つの商品画像（画像Aと画像B、またはセットAとセットB）を比較し、どちらがより購買意欲を高めるか評価してください。

【評価軸】（各1〜5点、整数のみ）
1. impression（第一印象・目を引く力）: スクロール中に手が止まるか
2. clarity（情報伝達の明確さ）: 3秒でこの商品の価値がわかるか
3. desire（購買意欲の喚起）: 「これが欲しい」と思えるか
4. trust（信頼感・プロ品質感）: 安っぽく見えないか、信頼できるブランドか
5. mobile（スマホでの可読性）: 文字・図が小さすぎず、スマホで快適に読めるか
6. visual_quality（視覚的プロクオリティ）: 「説明スライド」ではなく「Amazon商品画像としてのプロ感」があるか
   - 5点: Amazon売れ筋商品の画像レベル。テキストにメリハリがあり、写真が主役として機能している
   - 3点: 清潔だが平凡。情報は伝わるがインパクトに欠ける（スライド寄り）
   - 1点: スライドや説明資料のようで、Amazon商品画像として機能していない

【出力形式】
必ず以下のJSONのみを出力してください。他のテキストは一切含めないでください。

{
  "winner": "A" または "B",
  "scores_A": {
    "impression": 整数1-5,
    "clarity": 整数1-5,
    "desire": 整数1-5,
    "trust": 整数1-5,
    "mobile": 整数1-5,
    "visual_quality": 整数1-5,
    "total": 合計点
  },
  "scores_B": {
    "impression": 整数1-5,
    "clarity": 整数1-5,
    "desire": 整数1-5,
    "trust": 整数1-5,
    "mobile": 整数1-5,
    "visual_quality": 整数1-5,
    "total": 合計点
  },
  "winner_strengths": "勝った画像が優れている具体的な理由（2〜3点、日本語）",
  "loser_improvements": "負けた画像が改善すべき具体的なポイント（2〜3点、日本語）",
  "visual_quality_note": "visual_qualityの評価根拠（フォントメリハリ・奥行き・動感について具体的に）",
  "confidence": "high" または "medium" または "low"
}
