## 文字起こしスクリプト概要

### 出力ファイルパス
C:\Users\ninni\projects\awi\docs\松林社長\松林社長 年頭メッセージ（2026年1月）.txt

### なぜこのパスか
ユーザーの指示「MP4と同じフォルダに保存して」に従い、入力MP4と同じディレクトリ
（C:\Users\ninni\projects\awi\docs\松林社長\）に出力する。
ファイル名はMP4のベース名を踏襲し、拡張子のみ .txt に変更した。

### 実行コマンド
uv run python script.py

### スクリプトの概要
- ライブラリ: faster-whisper（WhisperModel）
- モデル: large-v2（日本語精度重視）
- デバイス: CPU、compute_type: int8（量子化で軽量化）
- 言語: ja（日本語固定指定）
- 出力形式: タイムスタンプ付きテキスト（[開始s -> 終了s] テキスト）

### 備考
ファイルサイズ258MB・約24分の音声のため、CPU実行では相当の時間がかかる見込み。
GPUが利用可能な場合は device="cuda" に変更することで大幅に高速化できる。
