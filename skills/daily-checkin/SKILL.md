# /daily-checkin — 日次振り返りヒアリング

前日の行動データを起点に、探索的な質疑で感情・充実度・テーマを記録するスキル。
life-strategy マップの全仮説（特にP01 幸福ドライバー）の検証データを蓄積する。

## 原則

- **固定の質問票にしない**。毎回同じ質問を繰り返すと形骸化する
- **行動データから話題を見つける**。ActivityWatch + Chrome履歴が質疑の起点
- **感情を深堀る**。「何をしたか」ではなく「どう感じたか」を引き出す
- **タグは探索的に増やす**。事前に決めた軸に押し込めない
- **短く済ませる**。3-5問で終わる。10分以内

## フロー

```
1. 行動データを自動取得（並行実行可）
   a. activitywatch スキルで前日のPC使用サマリー
      → カテゴリ別時間、22時以降の使用、主なアプリ
   b. Chrome履歴スクリプトで前日の閲覧サマリー
      → uv run python ~/.claude/skills/daily-checkin/scripts/chrome_summary.py --date {YYYY-MM-DD}
      → ドメイン別訪問数、主なページタイトル（時間帯付き）
   c. claude-mem でセッション履歴を取得
      → mcp__plugin_claude-mem_mcp-search__search で前日18:00〜翌06:00のセッション記録を検索
      → 何のプロジェクトで何に取り組んでいたかを時間帯別に整理
      → 特に22時以降のセッション内容は深夜作業の質問材料になる

2. 3つのデータを統合してサマリーを見せ、「昨日どうだった？」と聞く
   → ActivityWatch: 何にどれだけ時間を使ったか（アプリ単位）
   → Chrome: 具体的に何を見ていたか（URL/タイトル単位）
   → セッション履歴: Claude Codeで何に取り組んでいたか（プロジェクト・テーマ単位）
   → 組み合わせることで「14時にYouTubeで管理会計ツール比較を見てた」「20時以降はec-harnessのエージェント設計をしてた」等の具体的な問いが可能に

3. 探索的に深堀る（2-4問）
   → 感情に注目: 「それはどう感じた？」「一番良かった瞬間は？」「嫌だったことは？」
   → データに基づく具体的な問い: 「22時以降2h使ってたけど何してた？」
   → Chrome履歴から: 「午後にセールスイネーブルメントの動画見てたけど、何がきっかけ？」
   → 無理に深堀らない。ユーザーが短く答えたらそれでOK

4. テーマタグを抽出してユーザーに確認
   → 「今日のテーマは #達成感 #没頭 #時間不足 でよさそうですか？」
   → ユーザーが修正・追加・削除できる

5. 充実度を聞く（定義は固定。ブレを防ぐために毎回同じ基準で判定）
   | スコア | 定義 |
   |--------|------|
   | 5 | 「またこういう1日を過ごしたい」と思える日 |
   | 4 | 振り返って満足感がある。不満は小さい |
   | 3 | 可もなく不可もなく。印象に残らない |
   | 2 | 何かが引っかかる。後悔や不満が残る |
   | 1 | やり直したいと思う日 |

6. obsidian/diary に記録
   → 行動サマリーに Chrome履歴セクションを含める（主な閲覧を時間帯付きで）
```

## profile.json への記録ルール

**毎日は diary のみに記録する。profile.json への反映は週次または月次の life-session 時に diary を振り返って蒸留する。**

例外（即時記録してよいもの）:
- ライフイベント（入園、復職、引越し等）
- 明確な状態変化（新しい習慣の定着、関係性の変化等）

理由: diary が日次の生データ、profile.json が蒸留された事実。毎日書くと二重管理になり、「1回やっただけのこと」と「定着したパターン」の区別がつかなくなる。

## 記録先

`C:/Users/ninni/projects/obsidian/diary/{YYYY}/{YYYY-MM-DD}.md`

既存の diary エントリがある日は追記せず、別セクションとして統合を検討（基本は上書きしない）。

## 質疑のガイドライン

### 良い質問の例
- 「昨日一番エネルギーが高かった瞬間は？」
- 「逆に、気が重かったことは？」
- 「22時以降にClaude Codeを2h使ってたけど、何に取り組んでた？ それは楽しかった？」
- 「午後にセールスイネーブルメントの動画見てたけど、復帰に向けて意識してる？」
- 「Chatworkで代行会社とやり取りしてたみたいだけど、どんな話？」
- 「誰かと話した？ それはどんな感じだった？」
- 「今朝起きたとき、昨日を振り返ってどんな気分？」
- 「セッション履歴を見ると20時以降ずっとec-harnessのアーキテクチャ設計をしてたけど、没頭？それとも止められなかった？」（セッション履歴から）
- 「午前中はec-agentの設計、午後は広告分析と切り替えてたけど、どっちが充実してた？」（セッション履歴から）

### 避けるべきパターン
- SDTの軸を直接聞く（「自律性を感じましたか？」→NG）
- Yes/No で終わる質問
- 毎回同じ質問の繰り返し
- 10問以上の長い質疑

### テーマタグの例（これに限定しない。自由に増やす）
達成感, 没頭, 時間不足, 孤独, 家族, 感謝, 不安, 退屈, 成長, 自由,
疲労, 焦り, 充実, つながり, 創造, 学び, 停滞, 安心, 苛立ち, 驚き

## 蓄積データの活用

月次で life-strategy セッション時に diary データを分析する:
- タグの出現頻度ランキング → P01（幸福ドライバー）の検証データ
- 充実度スコアの推移 → 最上位仮説の検証
- 特定イベント（復職、AIDX配属）前後の変化 → P07, E04 等の検証
- Chrome履歴のパターン → 関心の変化、「構築→飽き」サイクルの検出

## 依存スキル

- `activitywatch` — PC使用データの取得
- `claude-mem` — セッション履歴の検索（claude-mem search で前日のセッション記録を時間帯別に取得）
- `life-session` — profile.json への fact 記録（週次/月次で蒸留時に参照）

## スクリプト

- `scripts/chrome_summary.py` — Chrome閲覧履歴の日別サマリー取得
