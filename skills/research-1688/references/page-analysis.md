# 1688商品ページ分析

サンプル候補確定後、工場問い合わせ前に実施する。
商品ページに記載されている仕様を事前に把握し、**ページで確認できない情報だけを工場に聞く**。

## 目的

- 工場への不要な質問を排除（ページ記載事項を聞くと嫌がられる）
- スペック情報を構造化して NocoDB に記録
- 工場ごとの問い合わせテンプレートを最適化

## 入力

ユーザーが以下のいずれかを提供:
- 商品ページのスクリーンショット（複数枚可）
- 商品ページのURL（agent-browser でスクショ取得）

**対象**: サンプル候補として確定した商品（Phase 4 Stage 3 通過品、通常10~15件）

## 分析項目

スクリーンショットから以下を抽出する。カテゴリによらず共通のフレームワーク。

### 基本情報（全カテゴリ共通）

| 項目 | 抽出元 | 記録先 |
|------|--------|--------|
| 価格テーブル（数量別単価） | ページ上部の価格表 | ai_note |
| MOQ（最低注文数） | 価格表の最小数量 | 1688商品.最低注文数 |
| 在庫数 | ページ記載 | ai_note |
| カラー/柄バリエーション | SKU選択エリア | ai_note |
| サイズバリエーション | SKU選択エリア | ai_note |

### 仕様情報（スペックマスタ項目に対応）

ページの「产品参数」「详情」セクションから抽出。

| 情報源 | 内容 |
|--------|------|
| 产品参数（商品パラメータ） | 素材、サイズ、対象月齢、認証、ブランド等 |
| 详情（詳細説明）画像 | 素材拡大写真、寸法図、工程写真、認証書 |
| メイン画像 | デザイン、仕上がり、素材感 |
| 商品タイトル | 素材名、機能キーワード |

### 工場情報

| 項目 | 抽出元 |
|------|--------|
| 工場名（正式名称） | 店舗ページヘッダー |
| 所在地 | 店舗情報 |
| 経営年数 | 店舗情報（「X年」表記） |
| OEM/ODM 対応表記 | ページ内の「加工定制」「贴牌」等の記載 |
| 認証・検査報告の有無 | 详情内の認証書画像 |

## 処理フロー

1. **スクショ受領**: ユーザーから商品ページのスクショ（またはURL）を受け取る
2. **AI画像解析**: Claude Vision でスクショを読み取り、上記項目を抽出
3. **構造化記録**: 抽出結果を NocoDB 商品スペックテーブルに記録
   - スペックマスタの項目に対応するものは `スペック値` に記録
   - ページから判定可能な項目は `スコア` も付与
4. **確認済み/未確認の分類**: 各スペック項目について「ページで確認済み」か「未確認（要問い合わせ）」かを分類
5. **ユーザー確認**: 抽出結果を提示し、誤りがあれば修正

## 問い合わせテンプレートへの反映

ページ分析結果に基づき、工場ごとに問い合わせ内容をカスタマイズする。

**質問に含めるもの（ページで確認できなかった項目のみ）:**
- OEM対応可否（ページに「加工定制」記載がない場合）
- カスタマイズの範囲（タグ変更、デザイン持ち込み等）
- 具体的な素材詳細（層数、生地厚さ等がページに記載なしの場合）
- サンプル費用・対応可否
- 実際の生産リードタイム

**質問に含めないもの（ページで確認済み）:**
- ページに明記されている素材・サイズ
- 価格表に載っている数量別単価
- 在庫状況（ページに表示あり）
- ページに写真掲載済みのカラーバリエーション

## NocoDB 記録

商品スペックテーブルに記録する際、`スペック値` に情報源を明記:

```
例:
  スペック値: "纯棉A类（ページ产品参数より）"
  スコア: 3

  スペック値: "未確認（ページ記載なし → 工場に確認要）"
  スコア: (空欄)
```

## 注意事項

- 1688のページ情報は**誇張や不正確な記載**がありうる。サンプル実物で最終確認が必須
- 详情画像は他社商品の転用の場合がある（特に低価格帯）
- 認証書の画像が掲載されていても、現行ロットに適用されるか確認が必要
- **スクショは商品ページ全体**を撮る（トップ、产品参数、详情の各セクション）
