# 評価基準（スペックマスタベース）

評価はすべて **スペックマスタ**（research-amazon-competitor Phase 3 で競合レビューから定義）に基づく。
スペックマスタの項目が変わるだけで、評価手法は商品カテゴリによらず共通。

## 用途

- **Phase 5（工場チャット後）**: 工場回答でスペック値を更新 → スコア再計算
- **Phase 7（サンプル実物）**: 全項目で最終スコア確定

> **注意**: Phase 4 の初期スクリーニングには使わない。Phase 4 は[フィルタリングプロセス](filtering-process.md)で絞り込む。

---

## スコア体系

### 商品スコア（0.0〜5.0）

NocoDB `1688商品.評価` に記録。`手動評価` カラムにはユーザーの主観評価を別途保持。

**各スペック項目のスコア:**

| スコア | 意味 |
|--------|------|
| 3 | 適合（スペックマスタの判断基準を満たす） |
| 2 | 条件付き適合（一部満たす / カスタマイズで対応可能） |
| 1 | 不適合（基準を満たさない） |
| — | 未確認（現フェーズでは判断不可 → 計算から除外） |

**総合スコア計算:**

```
評価 = Σ(項目スコア × 優先度重み) ÷ Σ(3 × 優先度重み) × 5
優先度重み: 高=3, 中=2, 低=1
未確認の項目は分母・分子ともに除外
```

### NocoDB 実装

Pythonスクリプトでの一括計算ではなく、NocoDB のカラム・数式で全計算過程を可視化する。
ユーザーが NocoDB UI 上で各商品の評価根拠をたどれる状態にする。

```
商品スペックテーブル（1レコード = 1商品 × 1スペック項目）:
  スコア (Number: 0-3)        ← 判定結果を格納
  スペック値 (Text)           ← 判定根拠（例: "6層", "防水記載あり"）
  優先度 (Lookup)             ← スペックマスタ.優先度 を自動参照
  優先度重み (Formula)        = SWITCH(優先度, "高",3, "中",2, "低",1, 1)
  加重スコア (Formula)        = {スコア} * {優先度重み}
  加重最大 (Formula)          = 3 * {優先度重み}

1688商品テーブル:
  加重スコア合計 (Rollup SUM) ← 商品スペックs.加重スコア の合計
  加重最大合計 (Rollup SUM)   ← 商品スペックs.加重最大 の合計
  評価 (Formula)              = IF(加重最大合計 > 0, ROUND(加重スコア合計 / 加重最大合計 * 5, 1), "")

1688工場テーブル:
  評価 (Rollup AVG)           ← 商品.評価 の平均（自動連動）
```

### 工場スコア（0.0〜5.0）

NocoDB `1688工場.評価` に記録。

**工場スコア = 紐付き商品スコアの平均**（常に商品スコアから導出）。
商品スコアが更新されれば工場スコアも連動して更新する。
工場の取引条件（OEM・MOQ等）は別軸で管理し、工場スコアには混ぜない。

## フェーズ別の評価精度向上

| フェーズ | データソース | 評価の性質 |
|---------|------------|-----------|
| Phase 4（リスティング） | フィルタリングで絞り込み（スコア不使用） | — |
| Phase 5（工場チャット） | 工場回答（素材詳細・MOQ・カスタマイズ可否等） | 中精度（回答内容でスコア付与） |
| Phase 7（サンプル実物） | 実物検査（洗濯テスト・触感・縫製等） | 確定評価（全項目） |

各項目のスコアは **商品スペックテーブル** の `スペック値` に根拠とともに記録する。
例: `6重ガーゼ・4層構造 → 3(適合)`

## 工場の取引条件（Phase 5 で収集）

工場チャット回答から得られる情報。スコアリングではなく**フィルタ／参考情報**として管理する。
チャットログテーブルに回答が蓄積されるため、別カラムでの管理は不要。
Phase 6 のサンプル絞り込み時に、手動評価上位の工場からこれらの条件で最終候補を選定する。

| 項目 | 確認内容 | 足切り基準（参考） |
|------|---------|-----------------|
| OEM対応力 | ラベル変更・印刷カスタマイズ・デザイン持ち込み | OEM不可 → 除外 |
| 価格 | 単価・版代・型代 | 利益シミュで赤字 → 除外 |
| MOQ | 最小発注量（色/柄別） | 月販予測の6ヶ月分超 → 要検討 |
| 納期 | 生産期間・出荷時期 | 参考情報（足切りなし） |
| 品質管理 | 検査報告・認証の有無 | 参考情報 |
| サンプル | 費用・対応可否 | 参考情報 |
| コミュニケーション | 回答速度・明確さ | 参考情報 |
